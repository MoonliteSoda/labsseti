# Лабораторная работа №4 — многоканальная система

Здесь размещается автомат состояний, связывающий Ethernet-передачу H.264 из ЛР-2 и низкоскоростную передачу изображений LoRa из ЛР-3.

Требования методички: независимый контроль доступности обоих каналов, режимы Ethernet/LoRa/нет связи, повторный поиск USB-устройства, устойчивое восстановление Ethernet, возврат на проводной канал после контрольных обменов и журналирование переходов.
