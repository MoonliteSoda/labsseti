# Лабораторная работа №3 — LoRa

Здесь размещается реализация передачи уменьшенных JPEG-изображений по последовательному интерфейсу LoRa и протокол УРВ-1. Код ЛР-3 изолирован от Ethernet-протокола ЛР-2.

Требования методички: кадрирование JPEG, сообщения размером до 128 байт с полезной нагрузкой до 114 байт, CRC-16, повторная синхронизация байтового потока, сборка изображения, ограничение очереди устаревших кадров и автоматическое переподключение USB-модема.
